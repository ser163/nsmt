NSMT / Yggdrasil — Net Share Memory Tree

A multi-tenant, multi-machine, multi-agent shared memory + shared file network layer in Rust (QUIC).
多租户、多机器、多 agent 的「共享记忆 + 共享文件」网络层：不同机器上的 agent 在同一用户域下共享记忆树与文件。

RustQUICP2P shared memoryfile syncmulti-agent E2E encryptionmulti-tenant

✦ Features / 特性

  • Identity & tenancy: FQN (user_domain/machine_id/agent_tag) + Ed25519 domain/machine auth
  • Shared memory: domain pool (authoritative) + local fallback, dual-write, network-first recall, sharded pools
  • Shared files: CAS objects + directory trees + lease locks + resume + conflict copies
  • P2P: application-layer peer auth (domain-key signature) + NAT hole punching
  • E2E encryption: per-tenant derived keys + seamless key rotation (ChaCha20-Poly1305)
  • Management: user system, per-user quota, ygg-admin supervisor + Web UI, backup/restore

🚀 Quick Start / 快速开始

cargo build --release
NSMT_ADMIN_TOKEN=secret ./target/release/nsmt-server 0.0.0.0:5555 --control 127.0.0.1:8091
NSMT_USER_DOMAIN=ser163 NSMT_AGENT_TAG=maka ./target/release/nsmt-client 127.0.0.1:5555
# conflict merge Web GUI:  ./target/release/nsmt-client 127.0.0.1:5555 conflicts-web 8088
